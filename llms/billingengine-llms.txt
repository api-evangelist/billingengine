# BillingEngine

> BillingEngine is online invoicing software for freelancers and small businesses in Germany. Every invoice is created as an e-invoice (ZUGFeRD and XRechnung, EN 16931), incoming e-invoices arrive in a dedicated inbox. It includes DATEV export, accountant access, a REST API and an MCP server. A permanently free plan is available. The interface is available in German and English.
